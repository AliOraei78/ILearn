# ILearn

کارگاه C# با Blazor Server، .NET 10 و ذخیرهٔ مستقل PostgreSQL برای هر حساب.

فصل‌های S01 تا S10 از مسیر قبلی آماده‌اند: ۸۰ چالش شامل ۵۱ بازی با پاسخ‌نامه، ۱۹ تمرین توضیحی و ۱۰ کارگاه کدنویسی. هر فصل مقدمهٔ ساده، راهنما و پاسخ تشریحی دارد و ۱۰۰ XP می‌دهد. حساب تازه از S01 شروع می‌کند؛ پیشرفت فصل‌های قبلی حفظ می‌شود. مسیرهای بازی بدون مدل هم قابل تکمیل‌اند.

[نقشهٔ راه نسخهٔ دوم](csharp-mastery-roadmap.md) مسیر آموزشی از صفر تا C# پیشرفته را با کدهای R001 تا R123 تعریف می‌کند. این کدها با فصل‌های فعلی برنامه یکی نیستند و پیاده‌سازی کامل مسیر جدید هنوز تأیید نشده است؛ وضعیت موجود و تطبیق هر ۴۴ موضوع قبلی در همان سند آمده است.

پوشش سرفصل‌ها، روش یادگیری و شواهد بررسی: [فصل‌های ۱ تا ۱۰](verification/chapters01-10-delivery.md).

## ساختار

راهنمای قواعد، کنترل‌ها و امتیازدهی همهٔ بازی‌ها: [MINI-GAMES.md](MINI-GAMES.md).

گزارش نهایی بررسی ظاهر، رفتار و اندازه‌ها: [ممیزی UI/UX](verification/ux-audit-2026-11-02.md).

- `ILearn.Domain`: مدل‌ها و قواعد مستقل از میزبان.
- `ILearn.Application`: قرارداد سرویس‌ها، هویت جاری و قواعد یادگیری.
- `ILearn.Infrastructure`: PostgreSQL، راه‌اندازی schema، SMTP، محتوای فایل و OpenRouter.
- `ILearn`: رابط Blazor، مؤلفه‌های تمرین، endpointهای حساب و composition root.
- `ILearn.Tests`: تست قواعد، محتوا، بازبینی AI و جهت وابستگی‌ها.
- `verification`: ابزار حساب تست، SMTP محلی و بررسی مرورگر.

وابستگی لایه‌های داخلی به میزبان و دیتابیس ممنوع است. تراکنش‌های حساب و قفل‌های PostgreSQL در Infrastructure باقی می‌مانند. وضعیت نمایش لابی در code-behind و ورودی تمرین‌ها در مؤلفه‌های مستقل است.

## اجرا و بررسی

تنظیمات اتصال و حساب‌ها: [POSTGRES.md](POSTGRES.md). تنظیم SMTP و جریان تأیید: [EMAIL-SETUP.md](EMAIL-SETUP.md).

```powershell
dotnet run --project ILearn --urls http://127.0.0.1:5080
dotnet build
dotnet test
docker compose up -d --build
```

Docker روی پورت 5081 اجرا می‌شود. دادهٔ حساب‌ها در volume اختصاصی PostgreSQL است؛ پشتیبان آن با pg_dump گرفته می‌شود. کلیدهای کوکی و اعتبارنامهٔ حساب تست در App_Data باقی می‌مانند و وارد image نمی‌شوند.

ورود فقط با ایمیل است. ذخیره‌ساز فایل و ورود قدیمی حذف شده‌اند؛ فایل‌های قدیمی به حساب‌ها وارد نمی‌شوند. قالب JSON پیشرفت و شناسه‌های محتوا حفظ شده‌اند. بررسی هوش مصنوعی اختیاری است و کد کاربر اجرا نمی‌شود.

بررسی پاسخ و توضیح درس فقط از مدل ثابت `nvidia/nemotron-3.5-super-vl:free` در OpenRouter استفاده می‌کنند. کلید را در `OPENROUTER_API_KEY` داخل `.env` بگذار؛ Compose آن را فقط به سرور می‌دهد. برای اجرای مستقیم، متغیر محیطی `OpenRouter__ApiKey` را تنظیم کن. کلید وارد گیت یا image نمی‌شود. هیچ مدل جایگزینی وجود ندارد؛ سقف قیمت ورودی، خروجی و هر درخواست صفر است و fallback سرویس غیرفعال است. خطاهای سرویس، سهمیه و اعتبار به کاربر نمایش داده می‌شوند. پاسخ نامعتبر حداکثر یک بار با همین مدل تکرار و سپس رد می‌شود.

پاکسازی حساب‌های تأییدشده یک‌باره و دستی است؛ هرگز هنگام اجرای برنامه انجام نمی‌شود. اسکریپت `verification/cleanup-approved-accounts.sql` به شناسه‌های مشخص محدود است و اجرای مجدد روی دادهٔ تغییرکرده را رد می‌کند.
