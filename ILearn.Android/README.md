# ILearn برای Android

نسخهٔ ۱.۰.۲ نمایش فارسی و کد، انتخاب‌گرهای جست‌وجوپذیر، تمرین‌های مرحله‌ای و ارزیابی مطابق پاسخ مرجع را با وب مشترک دارد. محدودسازی شبکه و runtime وصله‌شدهٔ 10.0.14 حفظ شده‌اند. [گزارش امنیت وب و Android](../verification/security-delivery-2026-11-05.md).

پروفایل، درس‌ها، پاسخ‌های مرجع و پیشرفت روی دستگاه‌اند. ساخت پروفایل به ایمیل، حساب وب، سرور یا PostgreSQL نیاز ندارد. سیو اندروید از حساب وب مستقل است.

هوش مصنوعی حذف نشده است: داوری آموزشگاه، کُد روم و مصاحبه و توضیح ساده‌تر پاسخ مرجع حفظ شده‌اند. برای این کارها اینترنت و کلید شخصی OpenRouter لازم است. کلید را از «پروفایل من، هوش مصنوعی» وارد کن. فقط مدل ثابت `nvidia/nemotron-3.5-super-vl:free` استفاده می‌شود؛ fallback غیرفعال و سقف قیمت هر درخواست صفر است. خطای سرویس یا نبود اینترنت پاسخ نوشته‌شده را حذف نمی‌کند. پاسخ‌نامه و ثبت شخصی بدون اینترنت در دسترس‌اند؛ کد کاربر اجرا نمی‌شود.

کلید در APK تعبیه نشده و کلید سرور وب خوانده نمی‌شود. در اندروید با AES/GCM و Android Keystore رمز می‌شود. پشتیبان شامل کلید نیست. نمایش مرورگری برای بررسی، کلید را فقط در sessionStorage نگه می‌دارد.

## نصب و پشتیبان

خروجی نهایی `artifacts/ILearn-offline.apk` است؛ Android 9 یا جدیدتر و Android System WebView به‌روز لازم است. APK امضاشده برای معماری‌های مختلف یکسان است. نسخهٔ `ILearn-offline-qa.apk` فقط برای آزمایش است و خروجی تحویل نیست.

پس از نصب، نام و کاراکتر را انتخاب کن. پیش از حذف برنامه یا پاک‌کردن داده‌ها، از پروفایل فایل پشتیبان بگیر. بازیابی فایل بعد از تأیید، سیو فعلی را جایگزین می‌کند. انتخاب و ذخیرهٔ فایل با فایل‌گیر استاندارد Android انجام می‌شود؛ مجوز عمومی حافظه لازم نیست.

## ساخت

رابط WebAssembly همان مؤلفه‌های Razor و قواعد بازی نسخهٔ وب را لینک می‌کند؛ محتوا از همان فایل‌ها داخل اسمبلی بسته‌بندی می‌شود. IndexedDB سیو را با تراکنش و بررسی revision نگه می‌دارد. میزبان Java فایل‌های داخل APK را با یک نشانی HTTPS محلی به WebView می‌دهد؛ سرور داخلی یا دانلود اولیه ندارد. فقط درخواست AI به نشانی ثابت OpenRouter از برنامه خارج می‌شود؛ پیوند منابع با تأیید در مرورگر دستگاه باز می‌شود.

ابزارهای لازم: SDK وصله‌شدهٔ .NET 10 با runtime حداقل 10.0.14 و `wasm-tools`، JDK، Android SDK Platform 34 و Build Tools 35.0.0. Gradle، MAUI و وابستگی Android خارجی استفاده نشده‌اند.

```powershell
./ILearn.Android/build.ps1 -Sdk "$env:LOCALAPPDATA/Android/Sdk"
```

اسکریپت publish، کامپایل Java و DEX، بسته‌بندی، zipalign و امضا را انجام می‌دهد. پوشهٔ محلی و نادیده‌گرفته‌شدهٔ `ILearn.Android/keys` را برای امضای به‌روزرسانی‌های بعدی نگه دار؛ کلید و رمز وارد گیت نمی‌شوند. شمارهٔ نسخه در `build.ps1` مشخص است.

## بررسی

```powershell
dotnet test ILearn.slnx --no-restore -m:1
node verification/offline-server.cjs
# در ترمینال دوم:
node verification/offline-flow.cjs
./ILearn.Android/build.ps1 -SkipPublish -Qa -Sdk "$env:LOCALAPPDATA/Android/Sdk"
```

تست مرورگر به Playwright نیاز دارد؛ مسیر نصب آن را با `PLAYWRIGHT_MODULE` می‌توان تعیین کرد. تست `verification/android-flow.cjs` فقط روی شبیه‌ساز QA اختصاصی `emulator-5556` اجرا می‌شود و دادهٔ همان نصب QA را پاک می‌کند. این تست را روی دستگاه شخصی اجرا نکن. پاسخ‌های AI در هر دو تست محلی و ساختگی‌اند؛ درخواست واقعی مدل ارسال نمی‌شود.

تست اختیاری زنده با `node verification/android-live-ai.cjs --synthetic-free` انجام می‌شود. این آزمون به کلید تنظیم‌شدهٔ پروژه، اینترنت شبیه‌ساز QA و APK بازشده نیاز دارد. پیش از ارسال، محتوای تمرین با سؤال عمومی ساختگی جایگزین می‌شود؛ کلید چاپ نمی‌شود، سقف هزینه صفر است و پس از تست از شبیه‌ساز حذف می‌شود. پنج درخواست زندهٔ آخر همگی HTTP 200 و هزینهٔ صفر داشتند؛ پاسخ واقعی پس از پاک‌کردن کلید و قطع اینترنت هم در دسترس ماند.

گزارش تحویل و محدودیت‌های آزمون در [android-delivery.md](../verification/android-delivery.md) ثبت می‌شوند.

مبنای میزبانی: [Blazor WebAssembly](https://learn.microsoft.com/en-us/aspnet/core/blazor/host-and-deploy/webassembly/?view=aspnetcore-10.0) و [بارگذاری محتوای داخل برنامه در Android](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content).
