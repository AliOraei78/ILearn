# بررسی و اصلاح امنیت ILearn

تاریخ: ۵ نوامبر ۲۰۲۶. پروژه: `E:\Products\ILearn`. دامنهٔ بررسی: وب Blazor، حساب و نشست، PostgreSQL، Docker، WebAssembly و میزبان Android، وابستگی‌ها، بسته‌های انتشار و تمام چهار commit تاریخچهٔ موجود. طبق تأیید مالک، هنوز استقرار اینترنتی وجود ندارد.

یافته‌های قابل اصلاح در این دامنه برطرف و نسخهٔ اصلاح‌شده اجرا شد. آزمون‌ها و اسکن‌های زیر مربوط به همین کد و بسته‌ها هستند؛ ادعای امنیت صددرصدی، مقاومت در برابر سیستم‌عاملِ تحت کنترل مهاجم یا گواهی انطباق نیستند.

## نتیجهٔ راستی‌آزمایی

- **۱۷۳ تست .NET: پاس، صفر skipped و صفر failure.** اجرای تست با host مستقل .NET 10.0.14 انجام شد؛ خود تست نیز runtime حداقل 10.0.14 را بررسی می‌کند.
- **۳۴ بررسی مستقیم دیتابیس:** روی PostgreSQL محلی Windows و سپس PostgreSQL Linux با نقش کم‌اختیار پاس شدند. شامل SQL injection، جداسازی حساب‌ها، stale revision، انقضای نشست و لغو دسترسی پس از تغییر رمز است.
- **۱۲ سناریوی وب HTTPS:** روی فایل اجرایی مستقل Windows نهایی پاس شدند؛ یک درخواست مدل فقط به fixture محلی ارسال شد.
- **چهار سناریوی Linux:** HTTPS، جعل forwarded scheme، cookie امن، ذخیرهٔ خصوصی، CSRF، حد فرم و خروج در کانتینر محدودشده پاس شدند. SHA-256 باینری `ILearn.dll` در QA و اجرای محلی یکسان بود.
- **اندروید:** شش جریان کامل در APK، هشت بررسی چیدمان و هفت سناریوی حمله پاس شدند. چهار درخواست AI ساختگی، بدون تماس با سرویس مدل واقعی. پروفایل، کلید رمز‌شده و draft بعد از خاتمهٔ process حفظ شدند.
- **مرورگر آفلاین:** نه جریان و ۱۱۰ بررسی چیدمان بدون خطا پاس شدند؛ ۱۳۵ تمرین و ۱۰۰ سؤال مصاحبه حاضر بودند. کلید غایب، رد و پذیرش پاسخ، پاسخ نامعتبر، لغو، خطای سرویس، تعارض revision و پشتیبان آزموده شدند.
- **وابستگی‌ها:** NuGet برای وب و Android، با وابستگی‌های گذرا، یافتهٔ شناخته‌شده گزارش نکرد. Trivy برای image فعال `ilearn:local`، image `ilearn-postgres:local` و بستهٔ مستقل Windows، **صفر CVE** در همهٔ شدت‌ها گزارش کرد. پایگاه CVE در ۵ نوامبر ۲۰۲۶ به‌روزرسانی شده بود.
- **اسکن رمزها:** منبع فعلی، هر چهار commit، بستهٔ وب و تمام فایل‌های APK با مقادیر واقعی کلیدهای محلی، بدون نمایش آن مقادیر، جست‌وجو شدند؛ **صفر یافته**. این اسکن به مقادیر فعلی و الگوهای مشخص محدود است و اثبات کشف هر نوع secret ناشناخته نیست.
- **APK انتشار:** امضای v3 تأیید شد؛ فقط INTERNET درخواست می‌کند؛ debug flag و cleartext و backup خودکار غیرفعال‌اند. نصب واقعی همان SHA-256 فایل تحویل را داشت؛ `run-as` رد شد و UID، پروفایل و Entries پس از به‌روزرسانی حفظ شدند. لابی با نام ذخیره‌شده و ۵۰ XP نیز به‌صورت تصویری بررسی شد.

## حفظ داده و اجرای محلی

خروجی‌های قدیمی PostgreSQL Debian به volume تازهٔ Alpine با dump منتقل شدند. تمام **نه جدول**، پیش از فعال‌شدن برنامه، شمار و هش محتوای یکسان داشتند. volume قبلی `ilearn_ilearn-postgres` حفظ شده است. dump و snapshotها در پوشهٔ خصوصی `ILearn/App_Data/backups/security-ilearn-20261105-132515` هستند؛ ACL فقط کاربر جاری، SYSTEM و Administrators را مجاز می‌کند. این فایل‌ها داخل بستهٔ انتشار نیستند.

نسخهٔ اصلاح‌شدهٔ محلی روی `http://127.0.0.1:5081` اجرا می‌شود. استثنای HTTP فقط برای همین اتصال محلی است. برای استقرار عمومی، HTTPS واقعی، دامنهٔ مجاز و پراکسی با IP مشخص لازم است. راهنمای اجرا در `SECURITY.md` و `POSTGRES.md` قرار دارد.

تغییر سازگار با امنیت: کاربران وب دوباره وارد می‌شوند. رمز قدیمی کوتاه یا قابل‌حدس باید با تأیید ایمیل عوض شود؛ حساب و سیو حذف نشده‌اند.

## حدود آزمون و شواهد

آزمون دستگاه فیزیکی، سرور اینترنتی، فایروال و گواهی دامنهٔ عمومی انجام نشده‌اند؛ استقرار اینترنتی وجود ندارد. Android روی شبیه‌ساز API 35 با WebView 124 و OS از نوع `userdebug` بررسی شد. این OS عمداً WebView inspection را حتی با درخواست غیرفعال‌سازی برنامه فعال می‌کند. بنابراین وجود socket تشخیصی در این QA به‌عنوان «غیرفعال بودن debug روی Android عادی» گزارش نشده است؛ Manifest انتشار، رد `run-as` و پیکربندی صریح برنامه جداگانه تأیید شدند. سیستم‌عامل عادی و WebView به‌روز، شرط استفادهٔ واقعی‌اند.

تست قدیمی صفحه‌کلید یک فرض همگام‌سازی نادرست داشت؛ به مشاهدهٔ وضعیت واقعی IME تغییر کرد. قطع موقت ADB با سرویس اختصاصی روی پورت محلی 5038 حل و آزمون‌ها از نو اجرا شدند. رفتار محصول برای عبور از این خطاهای ابزار تغییر نکرد.

Docker Scout به‌علت احتمال ارسال فرادادهٔ image خصوصی توسط بازبینی خودکار اجرا نشد. جایگزین، Trivy نصب‌شده با telemetry خاموش و اسکن کاملاً آفلاین بود؛ فقط پایگاه عمومی CVE جداگانه دانلود شد. هیچ image یا کد خصوصی برای این اسکن به سرویس بیرونی فرستاده نشد.

ابزارهای قابل تکرار: `ILearn.Tests`، `verification/SecurityChecks`، `security-web.cjs`، `security-linux.cjs`، `android-flow.cjs`، `security-android.cjs` و `security-artifacts.py`. تست‌های QA را به دادهٔ واقعی متصل نکن.

ساخت Docker روی SDK رسمی 10.0.403 تثبیت شده است. ابزار تست Windows با host مستقل و checksum‌شدهٔ 10.0.14 اجرا شد؛ نصب سراسری .NET تغییر نکرد. اسکریپت مهاجرت، volume تازهٔ بدون checkpoint تأییدشده را موفق فرض نمی‌کند.
