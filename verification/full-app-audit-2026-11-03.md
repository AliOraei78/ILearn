# ممیزی تمام بخش‌های ILearn، رابط و تجربهٔ کاربری

تاریخ: ۳ نوامبر ۲۰۲۶. وضعیت: هر ۲۱ مورد اصلاح و بازآزمایی شد؛ تمام اجراهای نهایی پاس شدند و یافتهٔ بازتولیدشدهٔ باز باقی نماند. این گزارش، یافته‌های این درخواست را ثبت می‌کند؛ تغییرهای قبلی مخزن و گزارش‌های تاریخی حفظ شده‌اند.

## دامنهٔ واقعی بررسی

| بخش | پوشش |
|---|---|
| معرفی و حساب | معرفی، ورود، ثبت‌نام، بازیابی، تأیید ایمیل، تعیین رمز، خطای درخواست و ۴۰۴؛ فرم نامعتبر با HTTP 400 |
| پروفایل | نام و رمز، نمایش ۴۸ کاراکتر، انتخاب و ماندگاری، ورود ماندگار، خروج، ابطال نشست و بازیابی حساب |
| آموزشگاه | ۱۲۳ واحد جاری و ۱۰ فصل آرشیو؛ هر ۱۳۳ مقدمه و تمام ۵۸۵ فعالیت در ۲۵ قالب |
| کُد روم | تمام ۱۳۵ تمرین، هر ۱۲ قالب، C#، PostgreSQL و Redis؛ فیلترها، نتیجهٔ خالی، لینک مستقیم و بازگشت به تمرین |
| مصاحبه | تمام ۱۰۰ سؤال C#، دسته و سطح، سؤال قبل/بعد، راهنما، مرجع و منابع، ذخیره و بازخورد |
| ویرایشگر و ذخیره | ورودی خالی، متن بلند، سقف ۱۶۰۰۰ نویسه، Tab و Shift+Tab، خروج با کیبورد، ذخیرهٔ معوق، تعارض تب‌ها و نشست منقضی |
| بازی‌ها | حل، راهنما، پاسخ صریح، تکمیل و XP، آزمایش و سهمیه، شروع مجدد، Undo، بازیابی و کنترل افشای پاسخ |
| پوسته و بازیابی | سایدبار، وضعیت انتخاب، منوی موبایل، Escape و فوکوس، پروفایل و برند، Back/Forward، بارگذاری مجدد و پنج حالت اتصال |

ماتریس پایه، ۴۶ اندازه از عرض ۲۸۰ تا ۳۸۴۰ پیکسل دارد؛ موبایل، تبلت، دسکتاپ، 4K، مرز breakpointها و ارتفاع کوتاه افقی را پوشش می‌دهد. افزایش اندازهٔ متن تا ۲۰۰٪ هم بررسی می‌شود. دو طرف مرز اختصاصی فضای کار، ۱۱۰۰ و ۱۱۰۱ پیکسل، در رگرسیون‌های تفصیلی بررسی می‌شوند.

تمام فعالیت‌های آموزشگاه و همهٔ تمرین‌ها و سؤال‌ها در چهار اندازهٔ پایه سنجیده می‌شوند. هر قالب و حالت‌های منتخب آن ماتریس کامل را می‌گذراند؛ تمام مقدمه‌ها نیز ماتریس کامل دارند. این پوشش، تمام ترکیب‌های ممکنِ اندازه، ورودی و وضعیت را شامل نمی‌شود.

مجموع ۱۴ اجرای نهایی مرورگر: ۶۲۲ گروه و ۴۱۹۴۶ اندازه‌گیری وضعیت/اندازه، بدون یافتهٔ چیدمان یا خطای مرورگر در خروجی‌های نهایی. هشت اجرای اصلی ماتریس، ۴۱۹۰۸ اندازه‌گیری دارند. [جمع‌بندی ماشینی محلی](full-app-results.json) کامل‌بودن و خالی‌بودن خطاها و یافته‌های گزارش‌ها را بررسی می‌کند و هش اسمبلی و CSS را ثبت کرده است. ساخت Windows و Linux/Docker موفق بود؛ برنامهٔ محلی روی پورت 5081 به‌روز و PostgreSQL سالم است.

پایگاه‌های ilearn_csharp_v2، ilearn_ui_audit و ilearn_full_audit برای حساب‌های آزمایشی جدا استفاده شدند. رگرسیون Docker فقط حساب مشخص با دامنهٔ example.test را به کار می‌برد. سرویس ایمیل و مدل در آزمون‌های جریان، محلی و قطعی‌اند؛ رگرسیون Docker درخواست مدل نمی‌فرستد. داده‌ها و volume اصلی PostgreSQL حفظ شدند.

فایل‌های بازتولید و خروجی:

خروجی‌های JSON و تصاویر طبق .gitignore محلی‌اند. نمونه‌های تصویری: full-app-after-{browser}-code-room-{390,1440}.png، full-app-after-{browser}-prose-390.png، [کُد روم دسکتاپ](code-room-docker-desktop.png)، [مصاحبهٔ موبایل پس از اصلاح](interview-docker-mobile.png) و [ناوبری مصاحبه پیش از اصلاح](interview-navigation-before-mobile.png). تصاویر منتخب نیز به‌صورت بصری بازبینی شدند.

برای بازتولید، ابتدا dotnet build و dotnet test -c Release را اجرا کن. full-app-audit.cjs میزبان، دیتابیس آزمایش، SMTP و مدل محلی خودش را راه می‌اندازد؛ --ux-only برای اجرای کوتاه حالت‌های UX است. برای تغییر مرورگر، ILEARN_FULL_BROWSER=msedge را تنظیم کن. رگرسیون آموزشگاه از build منتشرشده و Start-CSharpV2.ps1 استفاده می‌کند؛ برای اجرای مستقل Edge، پورت‌های میزبان، SMTP و مدل از طریق پارامترهای همان اسکریپت و متغیرهای ILEARN_V2_* جدا می‌شوند. PLAYWRIGHT_MODULE امکان استفاده از نصب موجود Playwright را می‌دهد؛ وابستگی جدیدی به محصول اضافه نشده است.

## حدود نتیجه

نتیجه به نسخهٔ فعلی، Chrome و Edge روی Windows، اندازه‌های ثبت‌شده و حالت‌های آزمایش‌شده مربوط است. Safari، Firefox، دستگاه فیزیکی، کیفیت واقعی داوری مدل و اثربخشی آموزشی برای یادگیرندهٔ واقعی در این نوبت سنجیده نشده‌اند. کد کاربر در محصول اجرا نمی‌شود. ادعای نبود تمام خطاهای ممکن مطرح نمی‌شود؛ هدف این بررسی، رفع تمام یافته‌های بازتولیدشده و بازآزمایی آن‌هاست.
