# اصلاح نمایش فارسی و تمرین‌های متمرکز

## تغییرات

- متن آموزشی، گزینه‌ها، پاسخ مرجع و بازخورد از نمایش مشترک `LearningText` استفاده می‌کنند: پایهٔ فارسی راست‌به‌چپ است؛ قطعهٔ لاتین و کد جهت مستقل دارد. درصد بازخورد با رقم فارسی و به‌صورت یک واحد نمایش داده می‌شود. HTML ورودی به‌صورت متن امن نمایش داده می‌شود.
- انتخاب سؤال مصاحبه، تمرین و فصل کد روم جست‌وجوپذیر است. هر صفحه حداکثر ۷ نتیجه دارد؛ ارتفاع نتایج محدود است. فوکوس جست‌وجو، Escape، صفحه‌بندی و تغییر فیلتر بررسی شده‌اند.
- سؤال چندگزینه‌ای درخواست پاسخ تشریحی ندارد. بازخورد مشاهدهٔ مثال فقط نتیجهٔ همان مثال را توضیح می‌دهد و خلاصهٔ کل فصل را تکرار نمی‌کند.
- ۱۲۳ فصل اصلی اکنون ۶۴۰ فعالیت دارند. ده فصل آرشیوی ۱۱۰ فعالیت دارند. ۱۰۰ موضوع مصاحبه در ۲۵۱ سؤال کوتاه تفکیک شده‌اند. کد روم ۲۱۳ تمرین دارد.
- کارگاه چاپ جمع، سمی‌کالن، comment و expression/statement در R002 چهار مرحلهٔ مستقل است. همین رویکرد در فصل‌های دیگر، از متغیر و حلقه تا Channel، DI، حافظه و انتشار، اعمال شده است. وابستگی‌های آمادهٔ قطعه‌کد کنار سؤال نمایش داده می‌شوند.
- شناسهٔ اصلی فعالیت‌ها حفظ شده است. مرحله‌های جدید شناسهٔ جدا دارند؛ ترتیب هشت فعالیت قدیمی هر فصل آرشیوی حفظ شده تا موقعیت سیو جابه‌جا نشود. تکمیل قدیمی به مرحله‌های تازه امتیاز نمی‌دهد.
- در تمام مسیرهای آموزشگاه، کد روم و مصاحبه، ارزیاب سؤال، معیار، قالب پاسخ، پاسخ مرجع، کد مرجع و فایل‌های مرجع را دریافت می‌کند. معیار نمی‌تواند الزام خارج از سؤال ایجاد کند؛ راه‌حل هم‌معنا پذیرفته است.
- تطبیق دقیق یک پاسخ مرجع کامل به مدل ارسال نمی‌شود و ۱۰۰ می‌گیرد. این روش فقط پس از تعیین صریح قالب پاسخ فعال است؛ تطبیق ناقص یا پاسخ متفاوت به ارزیاب می‌رود. مبدأ تکمیل «تطبیق پاسخ مرجع» از «بررسی مدل» جدا ثبت می‌شود.
- Android همان داده‌ها، مؤلفه‌ها و ارزیاب مشترک را بسته‌بندی می‌کند. شمارهٔ نسخه ۱.۰.۲ و versionCode برابر ۳ است؛ امضای قبلی حفظ می‌شود.

## شواهد

| بررسی | نتیجه و شاهد |
|---|---|
| تست‌های برنامه | ۱۸۱ تست، صفر شکست و صفر skipped؛ شامل صحت زمینهٔ داوری، تمام پاسخ‌های مرجع، مرز تطبیق، قالب متن و عدم اجرای HTML |
| صحت نحو پاسخ‌های C# | ۲۱۳ از ۲۱۳ پاسخ، با context آمادهٔ همان سؤال و source generator واقعی JSON، کامپایل شدند؛ `focused-code-report.json` |
| مرور کامل محتوا | ۷۵۰ فعالیت، ۲۵۱ سؤال مصاحبه و ۲۱۳ تمرین کد روم باز و پاسخ مرجع آن‌ها بررسی شد؛ `focused-browser-report.json` |
| چیدمان مرورگر | ۲۵ نوع بازی در عرض‌های ۳۹۰ و ۱۳۶۶؛ گزینه‌ها و انتخاب‌گرها در ۴۶ اندازه از ۲۸۰ تا ۳۸۴۰؛ متن ۲۰۰٪ در سه اندازه؛ بدون یافتهٔ نهاییِ سرریز، هم‌پوشانی یا هدف کوچک |
| وب واقعی | ثبت حساب با SMTP محلی، نشست واقعی Blazor Server و PostgreSQL جداگانهٔ `ilearn_focused_qa`؛ `focused-web-report.json` |
| ارزیاب واقعی | با اجازهٔ صریح کاربر، چهار درخواست به مدل رایگان ثابت OpenRouter؛ سه پاسخ متفاوتِ صحیح ۱۰۰ و پاسخ چاپ ۹ به جای ۱۰ نمرهٔ صفر؛ `focused-live-review-report.json` |
| Android | شبیه‌ساز اختصاصی emulator-5556؛ عمودی، افقی، فونت ۱۵۰٪، صفحه‌کلید، ذخیره پس از پایان فرایند، پشتیبان و انتخاب‌گرهای تازه؛ `android-report.json` |

فهرست قابل اسکرول در ممیزی با مستطیل واقعاً قابل‌دیدن سنجیده می‌شود؛ قسمت بریده‌شدهٔ دکمهٔ خارج از scrollport، هم‌پوشانی ظاهری شمرده نمی‌شود.

## بازاجرای بررسی‌ها

```powershell
dotnet build ILearn.Tests/ILearn.Tests.csproj --no-restore -m:1
dotnet test ILearn.Tests/ILearn.Tests.csproj --no-build --no-restore -m:1
python verification/check-focused-code.py
node verification/focused-ui.cjs --all
node verification/focused-web.cjs
node verification/android-flow.cjs
```

تست‌ها به runtime حداقل .NET 10.0.14 نیاز دارند. در این محیط runtime مستقل محلی از بسته‌های موجود NuGet برای اجرای تست و linker استفاده شد؛ runtime سراسری تغییر نکرد. آزمون مرورگر به خروجی publish در `artifacts/offline` و Playwright/Chrome نیاز دارد. آزمون وب پایگاه دادهٔ QA جدا و SMTP/مدل محلی می‌سازد. آزمون Android فقط نصب QA روی شبیه‌ساز مشخص را پاک می‌کند.

آزمون زندهٔ اختیاری `verification/ReviewChecks` فقط با `--live-free` اجرا می‌شود؛ چهار پاسخ عمومی و مرجعشان به OpenRouter فرستاده می‌شوند. کلید در گزارش ذخیره نمی‌شود. پاسخ‌های متنوع همچنان به ارزیابی مدل وابسته‌اند؛ کد کاربر در برنامه اجرا نمی‌شود. گوشی فیزیکی در این بررسی استفاده نشده است.

## بستهٔ نهایی Android

APK انتشار در `artifacts/ILearn-offline.apk`، نسخهٔ ۱.۰.۲ با versionCode=3، بدون debug و با امضای قبلی ساخته شد. حجم ۴٬۲۲۹٬۲۵۳ بایت است. نصب روی نسخهٔ QA پروفایل محلی را حفظ کرد و صفحهٔ آموزشگاه اجرا شد؛ `focused-release-report.json` و `focused-android-release.png`.

SHA-256: `503eb7303258a68957acf6bacaa541dbd1c1be40d5ef39c8b47de983add37a5b`.

خروجی publish پیش از بسته‌بندی نهایی پاک‌سازی شد. APK فقط یک اسمبلی برنامه و یک runtime WASM دارد؛ فایل برنامه همان `ILearn.Offline.yi6892xwgs.wasm` آزموده‌شده در مرورگر و QA است. بایت‌های اسمبلی و runtime داخل APK با خروجی publish یکسان‌اند.

## وب محلی

سرویس `ilearn` با `docker compose up -d --no-deps --build ilearn` بازسازی شد؛ سرویس پایگاه داده و volume آن جایگزین نشدند. نشانی محلی `http://127.0.0.1:5081` است. آزمون نشست و داده روی پایگاه QA جدا اجرا شده و محتوای داخل کانتینر نهایی با فایل‌های محلی تطبیق داده شد؛ صفحهٔ ورود HTTP 200 و CSS جدید داشت. نتیجه در `focused-deployment-report.json` ثبت شده است.
