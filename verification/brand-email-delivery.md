## Implemented

- Public introduction at /, authenticated lobby at /lobby. Requested book/code pixel SVG is used for brand links and favicon. Intro includes real current capabilities and account entry controls.
- Ordered subject list leads to chapters. Unscoped chapter shortcut removed. Lobby navigation and the icon-labelled profile action use native links with button styling.
- Profile updates username and optionally password only after current-password validation. Identity and progress retain the same ID. Password changes rotate the session stamp; middleware and live progress operations reject prior sessions.
- New accounts are created only after an email code is verified. Cryptographic six-digit code, keyed hash at rest, two-minute expiry/resend lock, five failed attempts, one account per normalized email, five sends/email/hour and 100 sends/network/hour. Durable transaction locks serialize limits across app instances. Existing account records and legacy JSON files are retained.
- OTP sending uses the platform SMTP client like RightPixel, with TLS by default. Own ILearn code key was generated. No SMTP credential was transferred from RightPixel.
