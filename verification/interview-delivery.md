# مصاحبهٔ C#؛ منابع و بررسی

تاریخ بررسی: ۳ نوامبر ۲۰۲۶. مسیر برنامه: `/interview`.

## محتوا و روش انتخاب

مجموعه شامل ۱۰۰ سؤال تألیفی فارسی با شناسهٔ پایدار C001 تا C100 است: ۲۶ مقدماتی، ۵۰ متوسط و ۲۴ پیشرفته. هر سؤال صورت روشن، سه معیار ارزیابی، پاسخ مرجع، راهنما و لینک منبع دارد. شش سؤال، کد کامل برای تحلیل خروجی یا خطای زمان اجرا دارند.

موضوع‌ها با مقایسهٔ فهرست‌های عمومی لینکدین، تکرار مباحث پایه و اهمیت عملی انتخاب شده‌اند. ترتیب، آموزشی است. منابع عمومی آمار جامع مصاحبه‌ها یا رتبه‌بندی عددیِ قابل‌اثبات برای این ۱۰۰ سؤال فراهم نمی‌کنند؛ این محدودیت در خود صفحه نیز بیان شده است. صورت سؤال و پاسخ‌ها برای ILearn نوشته شده‌اند و رونویسی از جواب‌های لینکدین نیستند.

| شناسه‌ها | دسته |
|---|---|
| C001–C010 | مبانی زبان و نوع‌ها |
| C011–C020 | طراحی نوع و امکانات زبان |
| C021–C030 | شیءگرایی و قراردادها |
| C031–C040 | جنریک و مجموعه‌ها |
| C041–C050 | LINQ و جریان داده |
| C051–C060 | متدها، رویدادها و خطاها |
| C061–C070 | برنامه‌نویسی ناهمگام |

| C081–C090 | حافظه و منابع |
| C091–C100 | سناریوهای عملی و عیب‌یابی |

## بازبینی کیفیت

هر ۱۰۰ سؤال از نظر یکتایی هدف، روشن‌بودن درخواست و تطابق سه معیار با پاسخ مرجع بازخوانی شدند. سؤال‌های مقایسه‌ای، دلیل انتخاب و مثال عملی می‌خواهند؛ معیارها نیازمند حفظ عبارت دقیق پاسخ مرجع نیستند. موضوع‌های اختصاصی SQL، EF و معماری توزیع‌شده برای پرکردن تعداد به بانک C# اضافه نشده‌اند.

نکته‌های مستعد خطا صریح شده‌اند: value type همیشه روی stack نیست؛ readonly و with تغییرناپذیری عمیق نمی‌سازند؛ IQueryable تضمین SQL نیست؛ All روی دنبالهٔ خالی true است؛ async thread تازه تضمین نمی‌کند؛ ASP.NET Core پیش‌فرض با context رابط کاربری یکی نیست؛ لغو همکاری‌محور است؛ factory در GetOrAdd ممکن است چندبار اجرا شود؛ Span در C# جدید محدودیت دقیقِ طول عمر دارد؛ پایان انتظار لزوماً عملیات اصلی را متوقف نمی‌کند.

## رفتار برنامه

فیلتر موضوع، دسته و سطح، انتخاب مستقیم سؤال و جابه‌جایی قبلی/بعدی آماده است. پاسخ مرجع پیش از بازکردن بخش مربوط نمایش داده نمی‌شود. ورودی تشریحی از ویرایشگر موجود با جهت RTL استفاده می‌کند و Tab معمولی از آن خارج می‌شود. پاسخ‌ها با تأخیر کوتاه و پیش از جابه‌جایی ذخیره می‌شوند.

پیشرفت در `Progress.InterviewQuestion` و ورودی‌های `interview/csharp/Cxxx` است. آموزشگاه و کد روم سیوهای مستقل دارند. تعداد سؤال‌های قبلاً تأییدشده نمایش داده می‌شود؛ مصاحبه XP جدیدی اضافه نمی‌کند. ویرایش پاسخ، بازخورد قبلی را پاک می‌کند؛ سابقهٔ تأیید قبلی همانند سایر فعالیت‌ها باقی می‌ماند.

داور، سؤال، کد احتمالی، پاسخ کاربر، معیار و پاسخ مرجع همان سؤال را دریافت می‌کند. مدل و محدودیت قیمت موجود حفظ شده‌اند: `nvidia/nemotron-3.5-super-vl:free`، بدون fallback و با سقف قیمت صفر. نمره، ایرادها و راهنمای اصلاح نمایش داده می‌شوند. خطا یا JSON نامعتبر سؤال را تأیید نمی‌کند؛ پاسخ محفوظ است. بررسی با ویرایش، لغو یا جابه‌جایی بی‌اثر می‌شود و نتیجهٔ قدیمی ثبت نمی‌شود.

## شواهد بررسی

- `dotnet test ILearn.slnx --no-restore -m:1`: ۱۴۵ تست پاس، بدون شکست یا skip. تست جدید برای هر ۱۰۰ سؤال، context ارسالی به داور را با دادهٔ همان سؤال تطبیق می‌دهد.
- `python verification/check-interview-examples.py`: شش مثال واقعی بانک کامپایل و اجرا شدند؛ پنج خروجی و یک `ArrayTypeMismatchException` موردانتظار درست بود. فایل‌های موقت خارج از پروژهٔ برنامه ساخته و پس از موفقیت پاک می‌شوند.
- `verification/interview-flow.cjs`: هر ۹ گروه رفتاری پاس شد؛ نمایش هر ۱۰۰ سؤال، پاسخ و منبع، اعتبارسنجی ورودی، ذخیره، ارزیابی ساختاریافته، خطا، لغو، فیلتر، ناوبری، موبایل و تداخل سیو با fixture محلی بررسی شدند. هر ۱۲ بررسی چیدمان، شامل عرض ۲۸۰ پیکسل و متن ۲۰۰٪، بدون ایراد بود؛ خطای JavaScript ثبت نشد. گزارش اجرا در `verification/interview-browser.json` تولید می‌شود.
- `docker compose up -d --build ilearn`: ساخت Release و بررسی وجود `Content/interviews.json` موفق بود. ذخیره‌ساز PostgreSQL و volumeهای موجود استفاده می‌شوند.
- `verification/interview-live-smoke.cjs`: هر سه گروه بررسی روی نسخهٔ Docker پاس شد؛ hash فایل منتشرشده با منبع یکسان بود. ورود به سؤال مشخص، همهٔ ۱۰۰ سؤال، سیو انتخاب، منابع و ناوبری بررسی شدند؛ چهار بررسی چیدمان هم پاس شدند. درخواست مدل ارسال نشد و خطای JavaScript ثبت نشد. گزارش در `verification/interview-docker.json` است.

تست رفتاری با fixture محلی، کیفیت قضاوت مدل واقعی را اثبات نمی‌کند. تلاش برای تست زندهٔ ده پاسخ مرجع در OpenRouter پیش از اجرا توسط بررسی خودکار مجوز رد شد، چون ارسال این سؤال‌ها، جواب‌ها و معیارها به آن سرویس اجازهٔ صریح جداگانه می‌خواهد. هیچ درخواست زنده‌ای برای این تست ارسال نشده است؛ ارزیابی معنایی مدل واقعی هنوز انجام نشده است.
